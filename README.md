EcoCamer 低功耗相机


是一款专为“羽毛球”、“网球”、“篮球”等“背景固定场景”设计的录制工具。

1，仅仅启动，非常纯粹的录制功能，不要其他一些列的功能（包括防抖），保证了超低电量功耗；

2，基于固定背景的视频保存逻辑优化，5分钟视频可以降到100兆，极致节省存储空间，并且画面不失关键部分。

我就是iphone录制羽毛球比赛视频发现太耗电了，存储的视频太大了，于是开发了这款app，不必担心手机电量和存储空间的问题咯。
不过，提示一下，如果是背景不固定，手持走动拍摄，那么还是建议用系统相机。
